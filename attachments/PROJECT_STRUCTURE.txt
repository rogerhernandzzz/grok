SKYNET - La Resistencia de Venezuela
=====================================

ESTRUCTURA DEL PROYECTO:

skynet/
├── backend/
│   ├── main.py                 # FastAPI app principal
│   ├── models.py               # SQLAlchemy models
│   ├── database.py             # DB config

│   │   ├── news.py             # Blog/noticias
│   │   ├── forum.py            # Foro pseudonímico
│   │   ├── admin.py            # Panel admin
│   │   └── trader.py           # Trader bot (simulado)
│   ├── services/
│   │   ├── payment_service.py  # Procesamiento pagos
│   │   ├── email_service.py    # Emails
│   │   └── crypto_service.py   # Cripto (Binance, Bitcoin)
│   ├── smart_contracts/

├── frontend/

│       ├── api.js              # Cliente API

TECH STACK:
- Backend: FastAPI + SQLAlchemy + PostgreSQL
- Frontend: HTML/CSS/JS (Vanilla)
- Auth: JWT + Face ID (local)
- Pagos: Stripe, Binance API, Bitcoin
- Blockchain: Solidity (smart contracts)
- Deploy: Render + Docker
- Dominio: vamosportidiosdado.render.com
