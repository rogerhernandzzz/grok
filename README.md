# SKYNET

Plataforma de La Resistencia. Chat, panel, moneda LUZ interna (sin cripto real) y portada con anillo en PC / tarjetas en móvil.

## Desarrollo

```bash
npm install
npm run dev
```

## Qué no va aquí

- Tokens, `.env` ni claves de API
- `node_modules`

Admin emite LUZ a miembros. Ellos pueden enviarse LUZ entre sí. No hay dinero real.
